# Midnight theme for OBS Studio

<img width="100%" src="https://raw.githubusercontent.com/frolovlife/frolovlife/refs/heads/main/assets/midnight-obs-theme/repository-open-graph-midnight-obs-theme.png">

**Midnight** is a minimalistic dark theme with a focus on being clean and unified in how it looks. The theme features medium contrast, and its rounded visual elements are complemented by new outlined icons, providing good visual orientation and reducing eye strain. Based on the original Yami Theme by @Warchamp7.

> [!IMPORTANT]
> Requires OBS version 30.2+ for compatibility.

You can star the repository so you don't lose this theme and update it regularly.

## 💡 Features

- Unique designed icons.
- Сolor scheme does not strain the eyes.
- Five styles of accent colors: blue, orange, pink, purple and red.
- Large, rounded, controls for easy interaction.
- Spacious widgets, for ease of use and visibility.

## 📥 Downloading

To begin installing Midnight theme, first download `.zip` archive with theme pack from **[Latest release](https://github.com/frolovlife/midnight-obs-theme/releases/latest)**.

## 💫 Automatic Installation

> [!IMPORTANT]
> For portable OBS Studio, only manual installation is available. For details, see the **[Manual Installation](#-manual-installation)** section.

### Windows

1. Extract the archive and run `Install_Windows.cmd` file.
2. Restart OBS Studio, then open OBS Studio settings and set the Midnight theme.

### macOS & Linux

1. Extract the archive and run `Install_UNIX.sh` file.
2. Restart OBS Studio, then open OBS Studio settings and set the Midnight theme.

## 💾 Manual Installation

1. Extract the archive.
2. In a separate window, open the OBS Studio theme directory for you operating system:
    - **Windows**: `%AppData%\obs-studio\themes\`\
      *(You can do this by using* `Win` *+* `R`*)*

    - **macOS**: `~/Library/Application Support/obs-studio/themes/`\
      *(You can do this in Finder with* `Cmd` *+* `Shift` *+* `G`*)*

    - **Linux**: `$HOME/.config/obs-studio/themes/`

    - **Portable OBS Studio**: `_OBS_PORTABLE_DIRECTORY_\data\obs-studio\themes\`

3. Copy `.obt` and `.ovt` files and `HollowDark` directory from extracted archive into the `themes` directory from step 2.

    List of files and folders to be copied:
    - `HollowDark\` — directory
    - `Midnight.obt` — file
    - `Midnight_Blue.ovt` — file
    - `Midnight_Orange.ovt` — file
    - `Midnight_Pink.ovt` — file
    - `Midnight_Purple.ovt` — file
    - `Midnight_Red.ovt` — file

4. Restart OBS Studio, then open OBS Studio settings and set the Midnight theme.

## 🗑 Uninstallation

1. Close OBS Studio.
2. Open the OBS Studio theme directory for you operating system:
    - **Windows**: `%AppData%\obs-studio\themes\`\
      *(You can do this by using* `Win` *+* `R`*)*

    - **macOS**: `~/Library/Application Support/obs-studio/themes/`\
      *(You can do this in Finder with* `Cmd` *+* `Shift` *+* `G`*)*

    - **Linux**: `$HOME/.config/obs-studio/themes/`

    - **Portable OBS Studio**: `_OBS_PORTABLE_DIRECTORY_\data\obs-studio\themes\`

3. Remove this directory and files from `themes` directory:
    - `HollowDark\` — directory
    - `Midnight.obt` — file
    - `Midnight_Blue.ovt` — file
    - `Midnight_Orange.ovt` — file
    - `Midnight_Pink.ovt` — file
    - `Midnight_Purple.ovt` — file
    - `Midnight_Red.ovt` — file
    - `Install_Windows.cmd` — file *(if it's present)*
    - `Install_UNIX.sh` — file *(if it's present)*

4. Start OBS Studio, then open OBS Studio settings and set an another theme.
